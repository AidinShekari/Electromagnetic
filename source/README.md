# Source material

The instructor's slides are the only authority for the academic content. They define the order
of the topics, the definitions, the derivations, the examples, the notation, the numerical
values and the figures.

| File | Content | Pages |
|---|---|---|
| `Ch1_1.pdf` | Part 1 of chapter 1: course outline, vector analysis, vector algebra, addition and subtraction | 11 |
| `Ch1_2.pdf` | Part 2: products of vectors, orthogonal coordinate systems, Cartesian coordinates | 21 |
| `Ch1_3.pdf` | Part 3: cylindrical and spherical coordinates | 20 |
| `Ch1_4.pdf` | Part 4: integrals containing vector functions | 15 |
| `Ch1_5.pdf` | Part 5: gradient, divergence, curl, vector theorems and identities | 21 |

The book currently contains only the material in these files. Each later chapter goes in its own
folder `NN-slug/{fa,en}/moduleNN-slug.md`, transcribed from its slides in order and in the same
format. The existing chapters stay unchanged.
